# Digital AI Agriculture

Python learning notes and practical exercises for digital agriculture.

This repository contains an introductory notebook with Korean lesson explanations, personal notes, and examples based on greenhouse temperatures, crop measurements, and sensor records.

## Start here

1. Preview [Python and data types](notebooks/01_python_and_data_types.ipynb) on GitHub.
2. Click **Open in Colab** below to run the notebook in your browser.
3. Save a copy to your Google Drive, then work through the cells in order.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/isabelhendrick-sudo/Digital-AI-Agriculture-/blob/main/notebooks/01_python_and_data_types.ipynb)

## Learning materials

### 01 · Python and data types

[View the notebook →](notebooks/01_python_and_data_types.ipynb)

- Using Google Colab and running notebook cells
- Variables, numbers, and arithmetic
- Comparisons and Boolean logic
- Strings, indexing, and type conversion
- Lists, dictionaries, tuples, and sets
- Processing a greenhouse sensor record

This is a working exercise sheet: some cells deliberately demonstrate errors, one asks for input, and the final exercise contains blanks to complete. Run it section by section; **Run all** will not finish successfully until these exercises are addressed.

The lesson uses Python built-ins, with no additional Python packages required. Use Google Colab or an existing Jupyter installation with Python 3.
